P3 civic-warm pixel — six poses with arms

Same palette, same head/cap/glasses/torso. Just the arms change. Pick a default pose for the welcome state — the others can become app-state poses later (idle, thinking, citing, refusing).

P3a — Arms at sides

Classic Funko stub-arms hanging straight down. Most-faithful Funko silhouette. Default neutral pose.

P3b — Hands clasped front

Politician/analyst pose. Reads composed and ready. Could be the default "thinking" pose.

P3c — Friendly wave

Right hand raised next to head. Welcoming. Strong candidate for the empty/welcome state.

P3d — Arms crossed

Confident, slightly skeptical. Could be the "refusal" pose ("I don't have a source for that").

P3e — Holding clipboard

Analyst at work. Could appear when retrieve() is running, or as a "citing source" pose.

P3f — Hands on hips

Confident, slightly heroic. "I've got this." Could be the post-answer success pose.

All six share the same body — only the arms change. So in the actual app we can swap poses by switching one <use> reference, which sets us up nicely for state-driven mascot animations later.
