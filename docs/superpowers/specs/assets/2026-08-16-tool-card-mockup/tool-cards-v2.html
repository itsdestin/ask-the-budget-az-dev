Proposed

Checked the house style for a research memo

Read JLBC's writing rules for a research memo before drafting. These are the rules it was given — advice, not enforcement: nothing checks the document against them afterwards.

Numbers. Round to one decimal place in the document body ($6.0 million). Keep the source's own precision in a chat answer ($6,043,200). Never build a total by summing the rows of a table.
Shape. Issue, background, analysis, options. Lead with the fiscal impact. Use bullets, never numbered lists.

The one judgement call. The current icons are pixel art, matching the mascot. That is a real house style and I am proposing to break it here — because these rows are chrome, the rest of the app's chrome is already drawn in lines, and the pixel style is precisely what made the magnifier unreadable at this size. If you would rather keep pixel art, the alternative is redrawing the magnifier larger; say so and I will mock that instead.
